## 作品について

雨で列車が遅れた夜、相沢直人は構内の案内に従い、「十三番線」へたどり着く。そこには古い列車と、直人を知っているのに彼には思い出せない同級生・水城綾乃がいた。

集まったのは八人。携帯はつながらず、来た道の先からは崩れる音が響く。助けを求めて最後尾から先頭へ進む一行を、誰かの持ち物や、傾いた車体、説明のつかない異変が待ち受ける。

一両ずつ奥へ進むほど、直人には短い記憶が蘇り始める。帰り道を探す夜は、いつしか隣を歩く人と、忘れていた過去をたどる夜へ変わっていく。

## この夜の手触り

雨に閉ざされた列車を、一両ずつ進んでいく。知らないはずの景色が、忘れていた誰かの声と、隣を歩く人の温度を連れてくる。

足場を確かめる緊張と、誰かを待つ時間。奇妙な車両をたどりながら、八人の言葉と行動が重なっていくノベルゲームです。
